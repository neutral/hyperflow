# Hyperflow

Hyperflow™ is an interaction model for the web: generated answers land as
ordinary, usable pages — Panels — in one ordered sequence, not as messages
in a chat transcript.

The spec prescribes the bare minimum on purpose — where this idea settles
is something building will find, and its terms and design are established
to communicate and to focus the search.

- [INTRO.md](INTRO.md) — the walk-through. Start here.
- [SPEC.md](SPEC.md) — the model: a short version, seven terms, four
  rules, and the license to break the rest.
